AI Search Algorithm Documentation & Theory

Comprehensive theoretical analysis, working principles, advantages, limitations, and asymptotic complexities for all six implemented algorithms.

1. Breadth-First Search (BFS)

Uninformed

Working Principle: Explores level-by-level using a FIFO Queue. All nodes at depth d are expanded before any nodes at depth d+1.

Time: O(bd)
Space: O(bd)
Completeness: Yes
Optimality: Yes (unit cost)
Advantages: Always finds the shortest path; guaranteed complete.
Limitations: Exponential memory growth.

2. Depth-First Search (DFS)

Uninformed

Working Principle: Explores deepest unexpanded node first using a LIFO Stack with cycle detection.

Time: O(bm)
Space: O(bm)
Completeness: No (infinite graphs)
Optimality: No
Advantages: Very low memory consumption O(bm).
Limitations: Non-optimal; can wander down deep paths.

3. Depth-Limited Search (DLS)

Uninformed

Working Principle: Constrains DFS exploration to a fixed depth limit L. Prunes any subtree extending beyond L.

Time: O(bL)
Space: O(bL)
Completeness: No (if d > L)
Optimality: No
Advantages: Solves infinite loop issue of DFS with bounded space O(bL).
Limitations: Fails with cutoff if goal lies deeper than limit L.

4. Iterative Deepening DFS (IDDLS)

Uninformed

Working Principle: Runs DLS iteratively for limits 0, 1, 2, ... d. Combines BFS optimality with DFS linear space.

Time: O(bd)
Space: O(bd)
Completeness: Yes
Optimality: Yes (unit cost)
Advantages: Optimal and complete like BFS, with linear O(bd) memory.
Limitations: Re-generates shallow nodes at each depth iteration.

5. Greedy Best-First Search (GBFS)

Informed

Working Principle: Expands node with lowest heuristic value h(n) using a Min-Heap Priority Queue.

Time: O(bm) worst
Space: O(bm)
Completeness: No (infinite space)
Optimality: No
Advantages: Extremely fast in practice; expands few states.
Limitations: Not optimal; can get trapped in heuristic local minima.

6. A* Search (A*)

Informed

Working Principle: Evaluates nodes via f(n) = g(n) + h(n). Min-heap extracts lowest f(n). Guarantees shortest path with admissible heuristic.

Time: O(bd)
Space: O(bd)
Completeness: Yes
Optimality: Yes (Admissible h)
Advantages: Optimally efficient among all heuristic search algorithms.
Limitations: Memory-bounded by open and closed lists in large spaces.

Interactive 8-Puzzle Problem Solver

The 8-Puzzle is a classical problem in Artificial Intelligence consisting of a 3x3 grid with 8 numbered tiles and one blank space. The objective is to transition from an arbitrary initial board configuration to a specified goal state by sliding tiles into the blank position.

Mathematical Solvability & Inversion Parity

Out of 362,880 total permutations, exactly half (181,440) are solvable for any chosen goal state. An inversion is any pair (a, b) with a > b where a precedes b. Legal tile slides preserve the even/odd parity of inversions:

Solvable iff: Inversions(Initial State) % 2 === Inversions(Goal State) % 2
